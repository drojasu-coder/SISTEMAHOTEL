# Clasificación

- `ESENCIAL`: contratos HTTP/OpenAPI, seguridad, arquitectura, Stripe,
  PostgreSQL, persistencia, constraints y concurrencia.
- `UTIL`: validadores, ownership, logger y configuración que cubren contratos
  específicos.
- `CONSOLIDABLE`: sólo como posible mejora futura; no se aplicó porque no hay
  duplicación inequívoca.
- `POSIBLE_DUPLICADO`: ninguno demostrado.
- `TEMPORAL`: ninguno identificado.
- `OBSOLETO_DEMOSTRADO`: ninguno.
- `REQUIERE_ANALISIS`: futuros helpers de fixtures, si aumentan las suites.

La cobertura o el número de asserts no se usó como criterio de eliminación.
