# Taxonomía

| Categoría | Aplicación |
|---|---|
| `ENV` | puerto, límites HTTP, CORS, rate limit, logging, URLs de base de datos y secretos |
| `CONSTANTE_APP` | nombres técnicos compartidos |
| `REGLA_DOMINIO` | métodos, tipos y moneda de pagos |
| `LITERAL_VALIDO` | rutas HTTP, status codes, mensajes y ejemplos Swagger |
| `TEST_FIXTURE` | credenciales y URLs aisladas de tests |
| `SECRETO` | JWT y credenciales Stripe provistas por entorno |
| `HARDCODING_SOSPECHOSO` | configuraciones o valores sin evidencia suficiente para modificar |

No se clasificaron reglas de dominio como `ENV`.
