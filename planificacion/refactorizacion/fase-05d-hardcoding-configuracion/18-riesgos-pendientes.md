# Riesgos y pendientes

- La configuración de slow queries existe pero no tiene instrumentación; no se
  implementó una feature nueva.
- Los estados repetidos entre dominios requieren decisiones específicas antes
  de centralizarse.
- Futuros endpoints o integraciones AWS deben añadir configuración sólo cuando
  exista implementación real.
- La deuda de tests, dependencias y estructura queda para Fases 5E–5G.
