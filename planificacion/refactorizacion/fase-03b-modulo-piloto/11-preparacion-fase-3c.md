# 11. Preparación para Fase 3C

Antes de extraer un segundo módulo se recomienda:

1. Confirmar con una prueba HTTP que Swagger conserva las cinco operaciones de sucursales.
2. Acordar si los routers documentados deben migrarse al módulo o permanecer como adaptadores.
3. Definir una regla automatizada de imports entre módulos.
4. Elegir un dominio de riesgo bajo/medio que no comparta archivos con José.
5. Mantener reservas, pagos, carritos y Stripe fuera del siguiente piloto.

La Fase 3C no se inicia automáticamente. Este piloto valida la dirección modular, no autoriza una migración masiva.
