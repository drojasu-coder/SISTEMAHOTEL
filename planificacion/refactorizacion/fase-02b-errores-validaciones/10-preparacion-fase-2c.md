# Preparacion para Fase 2C

La Fase 2B deja errores y validaciones con una representacion comun por campo,
respuestas seguras para fallos inesperados y mapeos explicitamente probados
para errores de PostgreSQL.

La Fase 2C no se inicia automaticamente. Antes de autorizarla se debe revisar
la suite completa, los riesgos pendientes y cualquier necesidad de modificar
contratos HTTP.
