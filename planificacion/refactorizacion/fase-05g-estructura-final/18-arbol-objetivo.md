# 18 — Árbol objetivo

## Ahora

Se conserva la estructura actual: `backend/`, `Frontend/`, `planificacion/`,
Docker y documentación de raíz.

## Después de 5G

La misma estructura, con documentación de Fase 5G añadida y decisiones
pendientes explícitas. No se crean carpetas vacías ni se mueven protegidos.

## Después de Fase 6

`Frontend/` podrá contener el scaffold React validado, preservando el material
visual existente y agregando `src/`, configuración, tests y cliente API.

## Futuro deploy

La infraestructura podrá incorporar Dockerfile/Nginx/TLS y documentación
`docs/deployment/`, manteniendo backend y frontend separados.
