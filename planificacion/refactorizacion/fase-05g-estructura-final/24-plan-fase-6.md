# 24 — Plan para Fase 6

Fase 6 preparará únicamente el scaffold base del frontend:

- React, TypeScript, Vite y Tailwind;
- React Router, TanStack Query;
- React Hook Form + Zod;
- Vitest y React Testing Library;
- cliente API y tipos generados desde OpenAPI;
- env example, providers, router, layouts y features.

Antes de crear archivos deberá preservarse el contenido actual de `Frontend/`
mediante una estrategia aprobada. No se sobrescribirán mockups, imágenes ni
`GUIA-DISENO.md`. Dockerfile frontend y Nginx quedan como diseño futuro.
