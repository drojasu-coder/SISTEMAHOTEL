# Documentación académica

| Elemento | Clasificación | Justificación |
|---|---|---|
| `DERCAS.pdf` | `NECESARIO_ENTREGA` o `REQUIERE_CONFIRMACION` | documento académico local |
| `dercas.txt` | `REFERENCIA` o `DUPLICADO` | texto asociado al DER; no comparar automáticamente |
| `TABLAS-Y-RELACIONES.md` | `NECESARIO_ENTREGA` o `REFERENCIA` | tablas y relaciones |
| `backend/dbml.txt` | `REFERENCIA` | modelo DB versionado |
| `script.sql` | `REQUIERE_CONFIRMACION` | puede ser entrega o SQL operativo |
| `Frontend/` | `REQUIERE_CONFIRMACION` | material de diseño local |

La ausencia de uso en runtime no justifica eliminar material académico.
