## Gestión Integral de Imágenes del Sistema (Hotel Hunahpú)

### 1. Infraestructura Compartida y Flujo de Subida

Se implementó una capa de almacenamiento y procesamiento multimedia desacoplada y reutilizable para todo el sistema en `backend/src/services/storage/mediaUpload.service.ts`:

1. **Presign de Subida (`POST .../:id/imagen-presign`):**
   - Emite URL prefirmada PUT hacia el bucket privado de AWS S3 (`hotel-hunahpu-media-2026`).
   - Genera una clave temporal `sedes/temp/<uuid>.<ext>` o `branding/temp/<uuid>.<ext>`.
   - Emite un ticket criptográfico HMAC-SHA256 (`uploadToken`) con validez temporal de 15 minutos que vincula la entidad, ID, usuario autenticado, tipo de contenido y expiración.

2. **Carga Directa Cliente -> S3:**
   - Realizada a través del cliente reutilizable `uploadEntityImage` (`Frontend/src/api/mediaUpload.ts`) vía `XMLHttpRequest` para monitorear el progreso exacto (0% a 100%).
   - Las credenciales de AWS nunca se exponen al navegador.

3. **Confirmación y Validación de Contenido (`POST .../:id/imagen-confirmar`):**
   - Valida la integridad del ticket y la idempotencia con la tabla `confirmaciones_subida` en PostgreSQL.
   - **Para fotografías (WebP / JPEG / PNG):** Descarga el búfer en memoria y realiza decodificación completa mediante `sharp` verificando límites de píxeles, dimensiones mínimas y encabezados de archivo; reempaqueta en WebP canónico optimizado.
   - **Para logotipos y branding (SVG / Imágenes):** Aplica sanitización estricta SVG rechazando `<script>`, handlers `on*` (`onload`, `onerror`, etc.), URIs `javascript:` y enlaces externos no seguros; o procesa WebP si es raster.
   - Traslada el objeto a su clave canónica final (e.g. `sedes/hotel-hunahpu-<slug>/<modulo>/<modulo>-<timestamp>-<uuid>.webp`).
   - Asocia el nuevo `imagen_key` al registro de la base de datos en una transacción atómica.
   - **Retención y limpieza:** Las claves oficiales precargadas (`KNOWN_ASSET_CREDITS`) están protegidas permanentemente de borrado. Para imágenes subidas por usuarios que son reemplazadas, `cleanStorageObjectIfUnreferenced` verifica en todas las 8 tablas del sistema si el objeto sigue referenciado antes de solicitar su eliminación de S3.

4. **Retiro de Imagen sin Eliminar la Entidad (`DELETE .../:id/imagen`):**
   - Permite que el usuario desvincule la fotografía de una sede, habitación, amenidad, actividad, salón o servicio de bienestar sin borrar la entidad de la base de datos.
   - La entidad vuelve de inmediato a su icono neutral de reserva (`fallback`).
